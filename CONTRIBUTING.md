# Contributing

1. Search existing entries before adding a new one to avoid duplicates.
2. Add your entry to the category that fits best, in alphabetical order within that category.
3. Use this format: `- [Name](link) - Short, factual description (one sentence, no marketing language).`
4. One resource per pull request.
5. Vendor/self-promotional submissions are welcome if genuinely relevant — no low-effort or duplicate listings.
6. Found a broken link or outdated entry? Open a PR or issue to fix or remove it.
